# Annotation Workflow

## Workflow Process

1. Image review and quality check
2. Label selection setup in CVAT
3. Polygon annotation for teeth and medical regions
4. Caries and treatment identification
5. Quality validation review
6. Export in YOLO, COCO, and CVAT XML formats

## Validation Process

- Cross-check label consistency
- Verify polygon accuracy
- Review missed objects
- Validate export formats

## Tools Used

- CVAT
- Manual Polygon Annotation
- Dataset Validation Workflow
