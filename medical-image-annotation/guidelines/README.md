# Annotation Guidelines

## General Rules

- Annotate only clearly visible teeth and structures
- Avoid overlapping polygons across separate teeth
- Maintain tight polygon boundaries
- Use consistent labeling standards across all images

## Tooth Annotation

- Label each tooth individually
- Separate molars, premolars, canines, and incisors correctly
- Use polygon annotation for irregular tooth shapes

## Caries Annotation

- Annotate only visible decay regions
- Avoid labeling shadows or reflections as caries
- Use precise segmentation boundaries

## Root Canal / Filling

- Mark only medically visible treatment regions
- Maintain annotation consistency across similar cases

## Quality Standards

- No missing annotations
- No duplicate labels
- Accurate boundary alignment
- Proper class selection
