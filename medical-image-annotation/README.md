# Medical Image Annotation

## Project Overview
Dental and medical annotation project focused on:
- Dental X-ray annotation
- Tooth segmentation
- Caries detection
- Root canal identification
- Implant and filling annotation

## Annotation Types
- Molar
- Premolar
- Canine
- Incisor
- Caries
- Filling
- Root Canal
- Implant

## Tools Used
- CVAT
- Polygon Annotation
- Medical Image Segmentation

## Use Cases
- Dental AI systems
- Medical computer vision
- Disease detection models
- Clinical AI training
