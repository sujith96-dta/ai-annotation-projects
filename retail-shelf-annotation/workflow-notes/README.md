# Retail Shelf Annotation Workflow

## Workflow Process

1. Image quality review
2. Product visibility assessment
3. Bounding box and polygon annotation
4. SKU grouping and shelf segmentation
5. Price tag annotation
6. Quality validation review
7. Export generation in YOLO, COCO, and CVAT XML formats

## Validation Process

- Verify missing products
- Check overlapping annotations
- Validate class consistency
- Review shelf segmentation accuracy

## Tools Used

- CVAT
- Bounding Box Annotation
- Polygon Annotation
- Dataset Validation Workflow
