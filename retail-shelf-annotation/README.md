# Retail Shelf Annotation

## Project Overview
Retail shelf annotation project focused on:
- Product detection
- SKU grouping
- Price tag annotation
- Shelf segmentation
- Product classification

## Annotation Types
- Product
- Product Group
- Price Tag
- Shelf Row
- Signage

## Tools Used
- CVAT
- Manual Bounding Box Annotation
- Polygon Annotation

## Use Cases
- Retail AI
- Smart inventory systems
- Shelf analytics
- Planogram validation
- Computer vision model training
