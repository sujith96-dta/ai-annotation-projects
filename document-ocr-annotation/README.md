# OCR Document Annotation

## Project Overview
Document annotation project focused on:
- Invoice extraction
- Air waybill annotation
- Packing list extraction
- Table structure annotation
- Key-value pair extraction

## Annotation Types
- Invoice Number
- Invoice Date
- Table
- Tax Amount
- Address
- Currency
- Product Description

## Tools Used
- CVAT
- Rectangle Annotation
- OCR Field Mapping

## Use Cases
- Intelligent document processing
- OCR model training
- Invoice automation
- Logistics automation
